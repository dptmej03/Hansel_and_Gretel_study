# Hansel-and-Gretel
스크롤하며 쿠키를 먹고 점수를 모으는 헨젤과 그레텔 공부법 크롬 확장 프로그램 🍪

헨젤과 그레텔이 빵 부스러기로 지나온 길을 표시한 것처럼, 공부하다가 쿠키를 하나씩 먹으며 어디까지 읽었는지 확인해 보세요. 쿠키는 지갑에 모이고, 상점에서 더 큰 점수를 주는 간식으로 바꿀 수 있습니다.

## 기능

- **쿠키 뿌리기:** 팝업에서 ▶ 시작을 누르면 페이지 세로 700px마다 쿠키가 하나씩 놓입니다.
- **쿠키 먹기:** 쿠키를 클릭하면 동전으로 바뀌며 사라지고 점수를 얻습니다. 먹은 자리는 새로고침해도 다시 나오지 않습니다.
- **지갑과 누적 점수:** 먹으면 지갑과 누적 점수가 함께 오릅니다. 지갑은 상점에서 쓰면 줄고, 누적 점수는 줄지 않습니다. 오늘 점수와 연속 공부일도 볼 수 있습니다.
- **간식 상점:** 지갑의 쿠키로 간식을 사면 그 간식이 페이지에 섞여 나옵니다.

| 간식 | 가격(쿠키) | 먹으면 | 등장 비율 |
|---|---|---|---|
| 🍪 쿠키 | 기본 제공 | +1점 | 나머지 |
| 🍫 초콜릿 | 10개 | +2점 | 약 33% |
| 🍬 사탕 | 30개 | +3점 | 약 20% |
| 🍰 케이크 | 80개 | +5점 | 약 10% |

## 설치 방법

Chrome 웹 스토어에는 아직 올라가 있지 않아서, 직접 불러와야 합니다.

1. [Releases](../../releases)에서 최신 zip 파일을 받아 압축을 풉니다. (또는 이 저장소를 `Code → Download ZIP`으로 받아도 됩니다.)
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 툴바의 퍼즐 모양 메뉴에서 이 확장 프로그램을 핀으로 고정하면 쿠키 아이콘이 보입니다.

## 사용 방법

1. 공부할 웹페이지(블로그, 강의 노트, 문서 등)를 엽니다.
2. 툴바의 쿠키 아이콘을 눌러 **▶ 시작 (쿠키 뿌리기)**를 누릅니다.
3. 스크롤하면서 쿠키를 클릭해 먹습니다.
4. 팝업의 상점에서 지갑의 쿠키로 간식을 삽니다.
5. 쿠키를 숨기고 싶으면 **⏸ 쿠키 숨기기**를 누릅니다.

## 주의사항
- 크롬 내장 PDF 뷰어와 `chrome://` 페이지에서는 동작하지 않습니다.
- 창 크기를 바꾸면 줄바꿈이 달라져서 쿠키가 글 속의 다른 위치에 놓일 수 있습니다.
- 데이터는 이 브라우저(`chrome.storage.local`)에만 저장됩니다. 크롬 사이트 데이터를 지우면 쿠키와 산 간식이 사라집니다. 서버로 보내는 데이터는 없습니다.
- 모든 웹사이트와 프레임에서 실행되도록 설정되어 있어서, 작은 광고 프레임 같은 곳에도 쿠키가 놓일 수 있습니다. 
- 쿠키를 읽지 않고 클릭만 해도 점수를 받을 수 있습니다. 읽었는지 검증하는 도구가 아니라 동기부여를 위한 도구입니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 설정(Manifest V3) |
| `content.js` | 페이지에 쿠키를 뿌리고, 먹으면 점수를 저장 |
| `cookie.js` | 쿠키, 동전, 간식의 픽셀 그림과 종류별 점수·비율 |
| `popup.html`, `popup.js` | 툴바 팝업(통계, 시작 버튼, 상점) |
| `icons/` | 툴바 아이콘 |

그림은 문자 격자로 직접 그려서 코드(`cookie.js`)에 들어 있습니다. 간식의 가격, 점수, 비율도 이 파일의 `SNACKS`에서 바꿀 수 있습니다.
